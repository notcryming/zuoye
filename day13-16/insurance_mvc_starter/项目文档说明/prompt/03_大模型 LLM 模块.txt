app/models/prompt_template.py——Prompt 模板 ORM 模型
字段：id、name、content、is_active、created_at、updated_at
类方法：get_active_template (db) /update_content (db, new_content) /init_default_template (db)
app/services/llm_service.py——LLM 底层调用服务
构造函数读取.env LLM_API_BASE、LLM_MODEL、LLM_API_KEY 配置，无密钥自动置空客户端实现降级
方法 build_customer_prompt (customer_row, template_content)：将客户编码字段反译为自然语言，填充模板占位符

app/utils/data_processor.py 补充客户画像文本转换工具：customer_to_natural_text (customer)
app/core/config.py 新增 LLM 相关配置字段读取
.env.example 补充 LLM_API_KEY、LLM_API_BASE、LLM_MODEL 环境变量配置
requirements.txt 追加 openai==1.51.0
【约束】
LLM 调用失败、未配置 API_KEY 时不抛出异常，返回 {success:False,error:xxx}，上层业务正常入库失败记录
Prompt 模板必须支持 {gender}/{age}/{vehicle_damage} 等占位符，模板存储于数据库，不硬编码在代码内
输出强制要求 JSON 结构 {"subject":"","content":"HTML 邮件正文 "}，自动过滤```json 标记
禁止直接向 LLM 传入 0/1 编码数值，全部通过反编码转换为中文描述
无并发异步，同步串行调用，单客户生成失败不阻断批量其他客户流程
【验收】
项目启动自动初始化默认生效 Prompt 模板至 prompt_templates 表
配置正确 LLM 密钥时输入客户画像可返回规范 JSON 邮件主题与正文
未配置密钥调用直接返回 success=False，无程序崩溃
模板更新功能可正常修改数据库内生效 Prompt 文本
