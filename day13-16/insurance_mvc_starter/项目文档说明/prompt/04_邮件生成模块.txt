1. 完整阅读 “项目文档说明 / 03_API 接口文档.md”“邮件模块/email” 全部接口定义、请求参数、分页结构、错误码、角色权限
2. 参考 “项目文档说明 / 01_PRD_产品需求文档.md” 高潜客户 top10% 分位数筛选业务规则
3. 参考 “项目文档说明 / 02_AI 技术方案.md”ML 概率分位数筛选逻辑、LLM 调用链路规范
4. 遵循 “项目文档说明 / 04_技术框架方案.md” 分层架构，路由、service、model 分层解耦
5. 对齐现有 api/v1 路由、models 模型、services 服务层代码编写规范，统一使用 BizException、标准分页、鉴权装饰器
【要创建 / 修改的文件】
app/models/email_record.py—— 邮件记录 ORM 模型
字段：id、customer_id、subject、content、status (generated/failed/sent)、created_by、created_at
类方法：batch_create (db, record_list) /paginate_records (db, user_id, page, per_page, status_filter) /get_by_id (db, record_id) /update_record (db, rid, update_dict) /patch_status (db, rid, new_status) /batch_delete (db, id_list)
app/services/email_service.py—— 邮件业务编排服务
方法 filter_high_target_customers (db, percentile)：读取 customers 表 predicted_prob，按分位数筛选高潜客户列表
方法 batch_generate_emails (db, customer_ids, limit, user_id)：循环调用 llm_service 生成邮件，批量入库成功 / 失败记录，返回成功、失败计数
方法 get_active_prompt (db)：读取数据库生效 Prompt 模板
方法 update_prompt_template (db, new_content)：更新模板内容
app/api/v1/email.py—— 邮件模块路由蓝图
GET /api/v1/email/targets（@login_required）高潜客户筛选接口，支持 percentile 分位参数、分页
POST /api/v1/email/generate（@login_required）批量生成邮件，支持 customer_ids 指定客户 /limit 取 top 客户两种传参
GET /api/v1/email/prompt（@login_required）获取当前生效 Prompt 模板
PUT /api/v1/email/prompt（@login_required）更新 Prompt 模板
GET /api/v1/email/records（@login_required）分页查询邮件记录，普通用户仅查看自己创建记录，admin 查看全量
GET /api/v1/email/records/<record_id>（@login_required）单条邮件详情
PUT /api/v1/email/records/<record_id>（@login_required）修改邮件主题 / 正文
PATCH /api/v1/email/records/<record_id>（@login_required）修改邮件状态
DELETE /api/v1/email/records/<record_id>（@login_required）单条删除邮件
DELETE /api/v1/email/records（@login_required）批量删除邮件
app/api/v1/init.py 注册 email 蓝图
app/models/customer.py 补充 find_high_potential 类方法支撑筛选功能
【约束】
分页接口全部使用文档统一分页返回格式 {items,total,page,per_page,pages}
无预测概率数据时抛出 BizException (code=3002)
批量生成时单客户 LLM 失败单独标记 status=failed，不中断批量流程
普通用户仅能查询、修改、删除本人生成的邮件记录；admin 可操作全部数据
所有接口必须携带 @login_required 鉴权装饰器，未登录返回 code=1002
分位筛选默认 0.9（取 top10% 高潜客户），支持前端自定义 percentile 传参
【验收】
存在预测概率数据时调用 /email/targets 可返回对应分位数高潜客户列表
调用 /email/generate 批量生成邮件后 email_records 表插入对应记录，区分 generated/failed 状态
普通用户只能查看自己创建邮件，admin 可查看全部
Prompt 模板读写、修改接口正常读写数据库 prompt_templates 表
单条 / 批量删除、修改邮件状态、编辑邮件内容接口正常生效
