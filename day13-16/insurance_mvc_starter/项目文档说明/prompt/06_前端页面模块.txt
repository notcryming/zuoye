请基于现有的保险精准营销后端接口，开发配套单页 SPA 前端管理后台，要求：
【参考资料】
1. 完整对照 “项目文档说明 / 03_API 接口文档.md” 全部 29 个后端接口地址、请求参数、返回字段、业务错误码
2. 参考 “项目文档说明 / 01_PRD_产品需求文档.md”RBAC 菜单权限规则：admin 展示 11 个菜单，普通 user 展示 7 个菜单
3. 遵循 “项目文档说明 / 04_技术框架方案.md” 前端目录规范，基于 Bootstrap5 + 原生 JS 开发无构建工具
4. 所有请求遵循后端统一鉴权规则：请求头携带 Authorization: Bearer token，统一处理 {code,message,data} 响应结构
【要创建 / 修改的文件】
app/static/index.html——SPA 主入口 HTML，hash 路由容器、侧边菜单栏、弹窗组件、分页公共组件
app/static/css/app.css—— 全局样式、菜单样式、表单、表格、弹窗、图表展示样式
app/static/js/api.js—— 统一接口请求封装工具
封装全局请求函数自动携带 token，统一捕获 code=1002 未登录跳转登录页，统一弹窗提示错误信息
按模块封装所有接口函数：authApi/dataApi/modelApi/emailApi/logApi，参数、请求方式严格对齐后端 API 文档
app/static/js/app.js—— 主逻辑、hash 路由管理、权限控制、页面渲染
路由：#login 登录页、#data 数据管理页、#model 模型训练页、#email 邮件营销页、#logs 操作日志页
权限渲染：登录后根据用户 role 动态渲染侧边菜单，admin 展示全部菜单，普通用户隐藏模型训练 / 模型导入导出 / 操作日志菜单
公共组件封装：分页渲染函数、base64 图片渲染、Excel 上传组件、批量操作弹窗、Prompt 编辑弹窗
各页面子渲染函数：
登录页面渲染：用户名密码表单，登录成功存储 token、用户信息到 localStorage 跳转首页
数据管理页面：Excel 上传、客户列表筛选分页、数据统计、EDA 图表展示
模型页面：一键训练、实验记录、最优模型查看、模型上传导出、评估图表展示
邮件营销页面：高潜客户筛选、批量生成邮件、邮件列表管理、Prompt 模板编辑、单条邮件详情修改
操作日志页面：仅 admin 可见，日志分页筛选查询
【约束】
路由采用 hash 模式，刷新页面自动读取 localStorage token 校验登录状态
所有后端接口返回图片 base64 字段直接渲染 img 标签
捕获所有接口错误码做对应提示：1002 跳转登录、1003 提示无权限、其他弹窗展示 message
表单提交增加简单前端参数校验，上传文件限制.xlsx 格式、10MB 大小
页面切换清空上一页查询条件，分页组件复用统一渲染逻辑
localStorage 持久化 access_token、当前用户信息，登出清空本地存储并跳转登录页
【验收】
访问根路径 GET / 自动加载 SPA 首页，未登录强制跳转 #login
admin 登录可见完整菜单，可完成：数据上传→模型训练→预测→筛选高潜客户→生成邮件→查看操作日志全流程
普通 user 登录隐藏训练、模型导入导出、日志菜单，访问受限接口弹窗提示权限不足
所有列表分页、筛选、新增、编辑、删除操作可正常调用后端接口并刷新页面数据
各类可视化图表（EDA、ROC、特征重要性等）base64 图片正常渲染展示
